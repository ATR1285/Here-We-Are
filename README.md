# Dayflow HRMS

Dayflow is a modern Human Resource Management System (HRMS) integrating a responsive vanilla HTML/JS frontend with a robust FastAPI backend. It replaces standard mock databases with true API connectivity to PostgreSQL, ensuring authentic data persistence and seamless user experiences across employee and administrative dashboards.

## Features

- **Authentication & Security:** Secure HTTP-only cookies managing state across all views.
- **Attendance & Time Tracking:** Real-time clock-in/out logging and history.
- **Leave Management:** Application flows, balances, and multi-tier administrative approvals.
- **Payroll Processing:** Auto-generated structured payslips based on base salary, allowances, and attendance factors.
- **Employee Directory:** Interactive profiles and administrative management of active status and roles.
